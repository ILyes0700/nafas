Pourquoi 3 horizons : +1h, +6h, +24h ?

+1h (court terme) — la meilleure précision : l'état actuel de l'air prédit presque directement l'heure suivante (RMSE le plus bas).

+6h (moyen terme) — utile pour anticiper une dégradation dans la demi-journée ; l'erreur augmente car davantage de facteurs (vent, trafic, rejets industriels) peuvent changer.

+24h (long terme) — le plus utile pour la population et les alertes, mais scientifiquement le plus difficile : l'incertitude météo s'accumule et l'erreur peut augmenter. Le système utilise uniquement les historiques, les variables cycliques et les variables météorologiques réellement disponibles. Aucune donnée synthétique n'est utilisée.
